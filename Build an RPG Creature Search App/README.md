# RPG Creature Search App

## Overview
The **RPG Creature Search App** is a web application that allows users to search for creatures from an RPG game by **name** or **ID**. The app retrieves creature data and images using the [freeCodeCamp RPG Creature API](https://www.freecodecamp.org/).

This project is ideal for learning how to interact with APIs, handle asynchronous requests, and dynamically display data in a user-friendly interface.

---

## Features
- Search for creatures by **name** or **ID**.
- Display creature **images** and **stats**.
- Responsive and intuitive UI for easy navigation.
- Error handling for invalid search queries or API issues.

---

## Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6+)** for app logic
- **Fetch API** to request data from the freeCodeCamp RPG Creature API
