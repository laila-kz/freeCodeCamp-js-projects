📞 Telephone Number Validator

A JavaScript application that checks whether a given string is a valid US phone number.
It supports multiple formatting styles as per US standards.


📜 Features:

-Validates US phone numbers in different formats.
-Ignores extra spaces before and after the input.
-Displays whether the number is valid or invalid.
-Lightweight and works entirely in the browser.


🚀 How to Use:

1-Type a phone number in the input box.
2-Click the Check button.
3-The app will display whether the number is Valid or Invalid
