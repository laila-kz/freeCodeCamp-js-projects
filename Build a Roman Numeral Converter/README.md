A simple JavaScript application that converts Arabic numerals (1–3999) into Roman numerals.


**Features
-Converts numbers from 1 to 3999 into Roman numerals.
-Handles invalid inputs and displays error messages.
-Simple and lightweight — no external libraries.
-Interactive UI with a Convert button.



**How to Use
-Enter a number between 1 and 3999 in the input box.
-Click Convert.
-The Roman numeral equivalent will be displayed.


***Technologies Used
_HTML
_CSS
_JavaScript (Vanilla)
