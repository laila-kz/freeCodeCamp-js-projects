# JavaScript Algorithm & Web Application Projects

A curated collection of core JavaScript algorithm and interactive web applications built as part of the **freeCodeCamp JavaScript Algorithms and Data Structures Certification**.

---

## 📚 Projects Overview

| # | Project | Description | Key Topics / Tech |
|---|---------|-------------|-------------------|
| 1 | [**Palindrome Checker**](./Build%20a%20Palindrome%20Checker/) | Evaluates whether a given string is a palindrome, ignoring non-alphanumeric characters, whitespace, and letter casing. | Strings, Regex, DOM Manipulation |
| 2 | [**Roman Numeral Converter**](./Build%20a%20Roman%20Numeral%20Converter/) | Converts standard Arabic numerals (1–3999) into their corresponding Roman numeral representations. | Greedy Algorithms, Number Mapping |
| 3 | [**Telephone Number Validator**](./Build%20a%20Telephone%20Number%20Validator/) | Validates US phone numbers across various valid national format variations. | Regular Expressions (RegEx), Validation |
| 4 | [**Cash Register**](./Build%20a%20Cash%20Register/) | Calculates exact change owed from a cash drawer with status indicators (`OPEN`, `CLOSED`, `INSUFFICIENT_FUNDS`). | Floating Point Math, Array Manipulation |
| 5 | [**RPG Creature Search App**](./Build%20an%20RPG%20Creature%20Search%20App/) | Queries an external RPG / creature database to fetch and display creature stats, types, and sprites. | Fetch API, Async/Await, Dynamic UI |

---

## 🛠️ Tech Stack & Concepts

- **Languages & Core**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **Data Structures & Algorithms**:
  - Array filtering, reduction, and mapping
  - Greedy change-making algorithms
  - String manipulation and sanitization
- **Web APIs & Features**:
  - Asynchronous HTTP requests using `fetch()` and `async/await`
  - DOM event listeners and dynamic element rendering
  - Form handling and user input validation
- **Pattern Matching**:
  - Advanced regular expressions for phone number and alphanumeric validation

## 🚀 Getting Started

All projects are built using pure Vanilla JavaScript, HTML5, and CSS3 without requiring external build tools, bundlers, or package managers.

### Running Locally

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd .js_projects
   ```

2. **Open any project**:
   - Navigate into the desired project folder (e.g., `Build a Cash Register`).
   - Open `index.html` directly in any modern web browser:
     ```bash
     # Example: On Windows
     start "Build a Cash Register/index.html"
     ```
   - Or use VS Code's **Live Server** extension for real-time live reloading.
