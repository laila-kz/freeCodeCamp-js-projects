# 🪞 Palindrome Checker

A **Palindrome Checker** web app that determines whether a given word or phrase is a palindrome — meaning it reads the same forwards and backwards, ignoring punctuation, case, and spacing.

## 📌 Objective

Build an app functionally similar to the [freeCodeCamp Palindrome Checker](https://palindrome-checker.freecodecamp.rocks).

The checker:
- Removes all **non-alphanumeric characters** (punctuation, spaces, symbols)
- Converts all characters to the **same case**
- Compares the string forwards and backwards to determine if it is a palindrome

---

## 🚀 Features

- Real-time palindrome validation
- Handles **words** and **full sentences**
- Ignores punctuation, case, and spacing
- Clean, responsive UI
- Lightweight and fast — pure JavaScript

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
